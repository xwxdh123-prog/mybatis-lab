# 实验一 AI 应用记录

## 使用目标

本次实验使用 Codex 协助分析实验指导书、生成 MyBatis 代码、执行测试并记录故障。根据实验要求，
数据表和初始数据没有照抄指导书示例；`emp` 表增加了 `email`、`phone`、`created_at` 字段。

## 主要交互与结果

| 交互内容 | AI 给出的结果 | 项目中的核验 |
| --- | --- | --- |
| 按任务一搭建 Maven、Git、MySQL 环境 | 生成项目结构、数据库脚本和 Git 配置 | Maven 构建成功，数据库含 5 条自定义员工数据 |
| 完成任务二基础 CRUD | 生成实体类、Mapper、XML、工具类和测试 | 查询、新增、修改、删除及主键回填测试通过 |
| 完成任务三动态 SQL | 加入 `if`、`where`、`set`、`foreach`、`choose` | 条件查询、动态更新、批量新增和删除测试通过 |
| 完成任务四 MyBatis-Plus | 接入 BaseMapper、QueryWrapper、LambdaQueryWrapper 和 Page | CRUD、条件查询及分页测试通过 |
| 完成任务五排错 | 复现属性名错误和主键未回填 | 两个错误均取得真实日志，修复后回归测试通过 |
| 使用 Apifox 调试公开接口 | 创建 `mybatis-lab` 项目并发送 GET 请求 | 响应状态为 200，返回 JSON 数据 |

## 人工校验项目

1. 数据库密码只在运行测试时输入到进程环境变量，不写入配置文件和 Git。
2. SQL 参数统一使用 `#{}`，没有把用户输入拼接到 `${}` 中。
3. CRUD、批处理和分页测试使用事务回滚，不改变五条初始数据。
4. MyBatis-Plus 首次运行缺少 Spring Core。检查异常类名后补充 `spring-core 5.3.30`。
5. 条件查询的预期数量先写成 3，真实种子数据只匹配 2 条。对照初始化脚本后把断言改为 2。
6. 用户明确取消 AI 插件步骤，因此项目没有安装或配置该插件。

## 使用边界

AI 生成的代码先经过编译和真实数据库测试，再进入提交。课程提交前，学生还应对照课堂讲解检查
命名、截图和报告格式，并用自己的语言说明代码作用。
